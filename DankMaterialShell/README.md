# DankMaterialShell (DMS) Configuration

Desktop shell environment configuration. DMS provides the bar, dock, launcher,
notifications, control center, and theming engine.

This is a third-party project shipped as a preconfigured dotfiles directory.

## Key files

| File | Purpose |
|------|---------|
| `settings.json` | All DMS settings (bar, widgets, colors, behavior) |
| `colors.json` | Material You color scheme (regenerated by matugen) |
| `themes/` | Custom theme presets |
| `plugins/` | Installed DMS plugins (FlatpakUpdates, etc.) |
| `styles/` | CSS-like style overrides |

## Controls

- SUPER+S: Open DMS settings
- SUPER+SPACE: App launcher / runner
- SUPER+ESCAPE: Control center

# SNAPSOS V2 Packaging


idea: complete rework of how SNAPS-OS is distributed

each module in its own git repo
standardized: configs in .config, program in .local, states in .cache, help menu reworked and modularized, firstrun.

new module: update manager (basically package manager lite)

each module in its own git repo:

repositories:

SNAPS-PKG - SNAPSOS package manager (and bootstrapper, can install all other packages)

unipkg - dependency of SNAPS-PKG for dependency installation. 

SNAPS-REPO - online repo SNAPS-PKG pulls from to know which repo's exist. 

SNAPS-MANGO-CORE - mangoWM, DMS, matugen configs, help menu (core, each package should bring its own help folder.)

SNAPS-TERM - ghostty, p10k and ZSH configs

SNAPS-MANGO-HELPERS - mango helper scripts

SNAPS-FETCH - fastfetch wrapper

SNAPS-GLYPHS - glyphs system

SNAPS-VOX - voice recognition system

SNAPS-WAYSHELL - wayshell base system

SNAPS-WAYSHELL-CONFIG - wayshell configurations. 

SNAPS-OS-THEMES - theme switcher package

dotfile-git-sync - dotfile git sync package

SNAPS-UTIL-SCRIPTS - utility scripts

SNAPS-TIPS - tips system, reworked to have a modular config that other packages can add tips to.

SNAPS-OS-DOCS


# standardized structure:

in each repo there should be:

scripts:
- install.sh - installs
- detect.sh - detects installation
- update.sh - runs an update
- uninstall.sh - uninstalls the module

dirs:
- local - files that go in ./local
- config - files that go in ./config
- cache - files that go in ./cache
- other - contains optional files that go in other directories (like .desktop entries)

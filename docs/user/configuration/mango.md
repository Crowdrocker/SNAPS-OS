# Mango WM Configuration

Configuration directory: `~/.config/mango/`

## File Structure

`config.conf` is the main entry point. It explicitly sources each subfile with `source=` directives:

| File | Purpose |
|---|---|
| `config.conf` | Main entry point; sources all other files via `source=` |
| `autostart.conf` | Applications launched on mango startup |
| `binds.conf` | All keybindings |
| `decoration.conf` | Window animations, blur, shadows, opacity, borders, tabs |
| `environment.conf` | Environment variables (NVIDIA, GTK theme, locale) |
| `input.conf` | Input device settings (keyboard repeat, touchpad) |
| `layouts.conf` | Tiling layout circle |
| `monitors.conf` | Display outputs (monitorrule= syntax) |
| `windowrules.conf` | Window rules: floating, opacity, layer animations, overlay |
| `matugen.conf` | Dynamic colors generated by Matugen |
| `dms/colors.conf` | DMS-managed colors for mango |
| `dms/layout.conf` | DMS layout gap settings |
| `dms/outputs.conf` | Output management (currently empty) |
| `dms/cursor.conf` | Cursor size |
| `dms/binds.conf` | DMS-specific keybinds (currently empty) |

## Auto-Start

`autostart.conf` runs these on mango startup:

- `xdg-desktop-portal` — portal service
- `tldr --update` — update tealdeer help pages
- `dsearch serve` — file indexer
- `hyprpolkitagent` — PolKit agent
- `firstrun.sh` — first-run setup UI
- `nautilus` — file manager service
- `dcal run -d --hidden` — Dank Calendar
- `~/.config/sdgos/wayshell/wayshell.sh` — Wayshell daemon
- `opentabletdriver` — tablet driver
- `dms run` — Dank Material Shell
- `ghostty` — terminal emulator
- Pre-loads a terminal scratchpad (×3 staggered launches)

## Window Rules

`windowrules.conf` configures per-window behavior:

- **Floating-Menu** windows: floating at 40% width/height (for script TUIs)
- **Firefox**: 95/85% opacity (focused/unfocused)
- **virt-manager + broken**: full opacity, broken is also fullscreen on HDMI-A-1
- **Layer animations**: fade for DMS layers, slide for Waybar
- **Glyphs overlay**: fullscreen transparent overlay at 50% opacity

## Input

`input.conf` configures:

- Keyboard: repeat rate (250), repeat delay (600), numlock on, xkb layout
- Touchpad: tap-to-click enabled, natural scrolling, disable while typing

## Environment

`environment.conf` sets env vars for:
- NVIDIA: `LIBVA_DRIVER_NAME=nvidia`, `GBM_BACKEND=nvidia-drm`, `__GLX_VENDOR_LIBRARY_NAME=nvidia`
- XDG desktop portal
- GTK theme (commented out)
- Locale

## Decoration

`decoration.conf` controls:
- **Animations**: global toggle, open/close/tag/focus/move with custom curves
- **Blur**: background and layer blur with configurable params
- **Shadows**: floating window shadows with size/blur/color
- **Opacity**: global focused/unfocused opacity
- **Borders**: radius (10px), width (2px), colors (active/inactive)
- **Tab bar**: border width, radius, padding, font
- **Jump mode**: label border, radius, padding, font

## DMS Subdirectory

The `dms/` directory bridges mangoWM and DMS:
- `colors.conf` — DMS-managed colors for mango borders and UI
- `layout.conf` — DMS gap settings (`gappih`, `gappiv`, `gappoh`, `gappov`)
- `outputs.conf` — output management (currently empty)
- `cursor.conf` — cursor size
- `binds.conf` — DMS keybinds (currently empty)
